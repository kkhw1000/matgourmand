# MatGourmand 커밋

- 커밋 대상 변경 사항을 확인하고 관련 없는 변경은 포함하지 않는다.
- 커밋 메시지를 한글로 작성한다. 필요한 경우 `feat(백엔드): ...`, `feat(웹): ...`처럼 영역을 구분한다.
- 작성한 코드에 맞춰서 현재 작업중인 브랜치와 작업내용이나 기능등이 일치하거나 비슷하다면 해당 브랜치에서 진행한다. 아니라면 적절한 브랜치를 생성한다.
- 커밋 전에 작업할 브랜치명과 메시지 초안을 함께 사용자에게 공유하고 검수를 요청한다. 수정 의견이 있으면 반영한 초안을 다시 공유한다.
- 사용자가 메시지를 검수한 뒤에만 커밋한다. 검수 전에는 `git commit`을 실행하지 않는다.
