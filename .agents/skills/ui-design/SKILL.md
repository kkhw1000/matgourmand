# MatGourmand 웹 UI 디자인

- 먼저 `web` 프로젝트에서 작업 대상과 관련된 컴포넌트·스타일을 확인한다. 현재 화면은 `src/App.jsx`와 `src/styles.css`에 있다. 사용자가 다른 방향을 요청하지 않았다면 기존의 따뜻한 색감과 카드 중심 디자인을 이어간다.
- React와 프로젝트의 Tailwind 방식을 사용하고, 같은 역할의 요소에는 일관된 스타일을 적용한다. 반복되는 값이나 전역 스타일만 필요에 따라 공통화한다.
- 변경한 화면을 좁은 모바일 화면부터 데스크톱까지 확인한다. 특히 320px 너비에서 가로 스크롤, 잘린 글자, 겹치는 조작 요소가 생기지 않도록 한다.
- 변경한 상호작용 요소의 선택·오류·빈 결과 등 해당 상태와 키보드 포커스, 텍스트 대비를 확인한다.
- 화면 확인 도구를 사용할 수 있으면 변경한 화면과 주요 상태를 실제로 살펴본다. 코드 변경 후 `web` 폴더에서 `npm run build`를 실행하고, 확인하지 못한 부분은 완료 보고에 적는다.
